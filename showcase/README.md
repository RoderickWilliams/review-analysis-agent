# 展示页（给 HR / 评审看的产品页）

`index.html` 是一个独立静态产品页，结构：导航、Hero、实测指标、工作流、内嵌演示工作台、能力、真实状态、本地运行、页脚。

## 内嵌演示

演示区是纯前端实现，内置样例数据，不请求本机服务、不访问真实平台：

- 左侧可切换总览 / 评论库 / 用户洞察 / 行动计划；
- 评论库里的“真实好评 / 疑似刷评”按钮会弹演示提示；
- 页面顶部明确标注“演示数据”，不冒充实机截图。

直接双击 `index.html` 即可查看，不需要启动工作台。真实工作台仍需本地运行（见仓库根 README）。

## 发布

把 `showcase/` 整个目录传到任意静态托管（GitHub Pages / Netlify / Vercel）即可；演示区离线可用，不依赖 127.0.0.1。

## 内容口径

- 实测指标沿用 2026-10-28 本机数据：同一天猫链接 33 条评论、14 条带正文、5 条有原句支持的痛点、单次分析 0.11 元。
- “真实状态”分开写跑通的与未验证的，不把规划写成现状。
- 不承诺单条评论真实性认证，只说明可信度信号与复核入口。
