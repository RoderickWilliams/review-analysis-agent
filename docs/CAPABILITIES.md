# ReviewAgent 能力与边界

本次升级已写入源码，尚未运行本轮测试、构建或界面验收。当前入口与安装方式见 [README](../README.md)，实现细节见 [升级交付说明](upgrade-implementation.md)。

| 需求 | 已写入的实现 | 结果的使用边界 |
| --- | --- | --- |
| 汇总平台评论 | CSV、Excel、JSON、TXT、粘贴、字段映射、逐行错误 | 文件导入不验证评论是否真实发布 |
| 情绪识别 | 逐条三阶段模型分析、三类情绪、独立反讽标记 | 尚未通过真实模型质量评测 |
| 定位内容疑点 | 模型内容可信度、重复、日期集中、评分分布等规则信号 | 不能确定刷单人数、AI 作者或真实购买身份 |
| 找用户痛点 | 原句校验、聚类、提及数、类别与严重度 | 原句吻合不等于事实已独立核实；最多 200 条成功样本 |
| 整理改进建议 | 依据已验证痛点生成建议与验证方式 | 成本与影响是初步分档，需业务确认 |
| 内容执行 | 选题、主图与详情页 brief、视频分镜、待确认参数清单 | 草稿，不生成已证实产品功效或成品图片 |
| 行动落地 | 生成行动清单，编辑负责人、日期、状态与指标 | 本地工作区，不包含通知或外部任务同步 |
| 中断恢复 | SQLite 逐条保存、取消后续请求、手动继续失败条目 | 单进程；已发出请求可能仍计费；重启不自动重跑 |
| 导出 | 原文和结果 CSV、行动 CSV、离线 HTML、JSON 快照 | 包含导入原文与来源信息 |
| 同款与采集 | 档位上限、时间窗、增量合并、公开搜索尝试、已有平台适配 | 未做真实平台验收；小红书自动跨平台确认同款未完整实现 |
| 评测 | 原有 eval 命令与 44 条样例集，新增离线回归 | 假模型测试只验证程序契约，不证明模型准确率 |

默认 Web 工作台为 /app/。旧 A、B 和 Streamlit 保留作为兼容入口；新任务、导入和行动功能以默认工作台为准。

未知评分和日期保留为空；导入时间独立保存。空样本不生成满分结论，模型失败不补成中性或常规评论。评分矛盾只作一致性提示，负面、低星和反讽不直接构成真实性扣分依据。

暂未实现或未验证：多用户权限与组织隔离、分布式队列与多进程调度、自动确认所有平台同款、可靠获取全量价格销量、真实模型准确率校准、真实登录采集端到端验收、公开部署验收。
