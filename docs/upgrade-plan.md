# ReviewAgent 工作台升级

## 已确认的决定
- 本轮在 `codex/reviewagent-upgrade` 独立工作树实施，基于 `origin/v2`，原目录与用户数据不覆盖。
- 沿用 Python 标准库、SQLite、FastAPI、现有分析器与 insights，不引入 React、Redis 或新的外部付费服务。
- 用户指定 oil-ui 参考图的浅色数据工作台方向；正式界面只做一个方向，旧页面保留在兼容入口。
- 生成测试与验收方案属于实施；执行检查需另获一次明确批准，不自动运行或反复验收。

## 依赖顺序与接口

### 1. 共用可靠性
- 新增统一评论输入、模型响应和统计处理，保留原文、来源、未知日期与稳定评论 ID。
- 成功/失败独立计数；失败不参与情绪、真实性比例和均分。情绪三分类与反讽标志分离。
- 可信度不因负面、反讽自动扣分；异常只作为需复核的信号。
- DeepSeek 配置与 Key 轮换按实际请求生效；输出错误不包含凭据或原始服务端错误。
- HTML 文本统一转义；CSV 危险公式前缀中和；短文本不触发空词表异常。

### 2. 工作台服务
- 对象分析保存 `request` 输入快照、`reviews`、`results`、进度、报告和错误。
- `POST /v1/analysis` 保持兼容同步对象解析；增加后台任务、详情、取消、重试与评论导入接口。
- 以 SQLite 中的分析记录作为任务持久状态；线程池执行，逐条保存，可恢复失败条目；重启后标注中断，不静默重跑产生费用。
- 深度分析显式启动，未配置模型时保留数据并说明缺口；运营方案按需生成并缓存。
- 聚合数据必须区分真实采集事实、程序统计、建议和文案；证据引用原评论 ID。

### 3. 前端
- 原生 HTML/CSS/JS，统一浅灰绿侧栏、白色内容、细边框、绿色主动作。
- 一级导航：总览、评论、洞察、行动、历史；详情内提供对象、覆盖与证据。
- 支持 CSV/Excel/JSON/纯文本导入、字段映射与预览，未知日期不补当天。
- 结果以可筛选表格、失败状态、证据抽屉、明确进度和导出组织；刷新恢复完整请求。
- 键盘弹窗焦点管理、窄屏导航、减少动态效果；仅按用户操作做短过渡。

### 4. 扩展采集
- 档位、时间窗、平台与候选上限成为真实参数；解析与采集分开，缺样本不生成结论。
- 复用现有平台采集器及小红书适配，只有配置开关与用户请求均允许时才启动。
- 候选发现保留原链接、平台与匹配理由；跨平台未成功时返回明确缺口。
- 增量合并按平台/商品/原评论 ID 去重；同文不同评论保留用于重复信号统计。

### 5. 交付
- 禁止打包 `.env`、Cookie、浏览器 profile、数据库、运行输出。
- 移除硬编码旧项目路径，保留兼容静态资源；增加可选部署访问令牌与文件路径边界，不替用户创建令牌。
- 增加 CI、依赖约束与安装/恢复说明；不在本轮推送、发布、部署或迁移数据。

## 待批准的单次验证范围
- 离线 pytest、Python 语法与前端脚本语法、构建资源白名单检查，使用隔离临时目录和假模型。
- 桌面 1440px、移动 390px：导入、后台进度、失败重试、历史恢复、证据、导出、取消和键盘操作。
- 真实登录采集、真实模型质量、公开部署需单独提供相应条件与授权。
