# 统一验收范围与实施边界

本轮围绕用户确认的 Folkmanis 业务场景验收。先完成源码，再执行一轮约定检测；下表不代表已通过。修复后不自动重复验收。

| 能力 | 当前实现 | 验收方式 |
| --- | --- | --- |
| 专用浏览器登录 | 默认 Chrome/Edge/Firefox 程序，平台独立配置；扫码、取消、会话复用及超时；只关闭自有窗口 | 离线回归 + 本机实际扫码 |
| 同款检索 | 三平台真实搜索锚点、平台配额、候选检查点、缺口记录 | Fake driver 契约 + Folkmanis 搜索 |
| 真实采集 | 与登录共享配置；京东/淘宝 DOM 解析、小红书评论 DOM；限速、退避、人工验证、逐批落库 | 实际平台采集，分别记录数量和限制 |
| 严格归并 | 品牌、型号、关键规格一致才合并；SPU/标题相似不授权归并；来源身份可编辑，未知规格独立待确认 | 分组回归 + UI 核对 |
| 采集规模 | 标准每来源最多 300 条、12 个月优先，较早补样/日期未知另标；整份研究最多 5000 条 | 时间窗及边界用例 + 实际缺口 |
| 模型分析 | 全部原文保留、本地去重统计、平台/组/评分代表样本最多 120 条，每批 10 条；洞察逐组生成 | Fake model 完整链路 + 一份真实报告 |
| 费用 | DeepSeek 官方 API、非思考、每请求最多 2048 输出 token；付费前预留；usage 估算、超时保留预留；重试沿用账本 | 预算单测 + 真实 usage 记录 |
| 费用上限 | 目标低于 1 元，允许上浮 0.5 元；评论阶段预留至 0.8 元，洞察阶段新请求停止线 1.4 元，总上限 1.5 元 | 按官方高峰价保守计，最终与供应商账单区分 |
| 运营输出 | 有证据的诊断、优先级、验证指标；卖点/客服/选题/排期可编辑；保留人工修改；区分运营准备与负责人确认 | 编辑、重新生成、刷新恢复及导出 |
| 历史管理 | 完整原文/结果/草稿保存；清除为可恢复隐藏，运行中阻止清除，支持最近批次撤销 | 隔离数据库验收，不清理用户真实数据 |
| UI | 用户 Logo，Vesper/oil-ui 风格；1440×900 主框、14px 圆角，小屏收缩、内部滚动；顶部固定；保留搜索焦点 | 桌面/窄屏、滚动条拖动、键盘与状态截图 |
| 导出 | 评论 CSV、行动 CSV、草稿 CSV、完整 JSON、离线 HTML；转义与公式安全 | 实际下载、内容核对与 XSS 回归 |
| 打包 | wheel 资源与 PyInstaller 白名单含新 JS/Logo，排除 Cookie/浏览器配置等运行数据 | wheel 构建与资源扫描 |

## 约束
- 单机、单 Uvicorn worker、最多两个后台工作线程；未实现组织隔离或分布式任务。
- 平台登录/页面结构和风控受外部条件影响，不承诺所有来源必定采满或会话永久有效；遇到验证交由用户，不绕过。
- 小红书采集对象是笔记评论，与购买评价分别标记；未知商品规格不归入其他商品组。
- 模型覆盖范围与原文总量分开报告；未选中的评论不冒充已逐条模型分析，情绪分布以成功模型样本为分母。
- 费用定价快照为 2026-10-27 官方高峰价；缓存命中、空闲时段可能更低；不确定用量按预留保守计，不伪装成已核对账单。
- 真实模型验收仅一份报告，最高 1.5 元；无真实评论时不伪造，也不把假模型结果写成真实验收通过。
- 不发布、推送或迁移用户数据库；原测试 snapshot 与旧预览保留，新预览另建副本。
