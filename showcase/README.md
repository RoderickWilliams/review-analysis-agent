# 展示页（给 HR / 评审看的产品页）

`index.html` 是一个独立的静态产品页，参考 SaaS 产品官网的结构：导航、Hero、指标、问题、流程、能力、真实状态、内嵌演示、页脚。
图片来自本机工作台的实拍截图（`assets/`），没有用示意图冒充实机。

## 打开方式

直接双击 `index.html` 即可（图片相对路径）。

内嵌演示区需要本机工作台在跑：

```cmd
cd E:\review-analysis-agent
venv\Scripts\python.exe run_local.py --port 64628
```

页面里 iframe 指向 `http://127.0.0.1:64628/app/`。服务没启动时 iframe 是空白，页面其余部分照常显示。

## 发布

想公开托管时，把 `showcase/` 整个目录传到任意静态托管（GitHub Pages / Netlify / Vercel）即可；
内嵌演示区在公网无法连到本机服务，届时可以替换成录屏或截图。

## 内容口径

- 指标是 2026-10-28 本机实测：同一天猫链接 33 条评论、14 条正文、5 条带证据痛点、单次分析 0.11 元。
- “真实状态”两栏只写跑通过的与明确没验证的，不把规划写成现状。
- 页面不承诺单条评论真实性认证，只说明可信度信号与复核入口。
