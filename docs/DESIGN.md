# 工作台设计方向

北极星：让运营人员像核对账目一样核对评论，先看样本与处理状态，再追到原句和下一步行动。

用户参考：Vesper Billing overview 截图（oil-ui）。借鉴的是信息密度、浅灰绿色侧栏、白色画布、细边框、低饱和绿色、紧凑表格和清楚的主次，不复制其品牌或账单内容。

## 视觉与内容
- 画布 `#e4ebe6`，侧栏 `#f4f6f5`，内容白色，边框 `#e2e7e4`，文字 `#202b26`，主色 `#27785d`；错误与待处理分别使用红色与琥珀色，并始终带状态文字。
- 使用系统无衬线字体，中文回退苹方/微软雅黑；标题 24–28px，正文 14px，表格 13–14px，辅助说明不小于 12px；数字使用 tabular-nums。
- 桌面侧栏 224px，顶部栏 60px；总览由左侧关键指标与右侧真实时间分布组成，下方是标签、筛选和评论表格。
- 外框固定为 1440 × 900px，圆角 14px；较小窗口按可用宽高缩小。禁止内容撑高整页，顶部栏固定，主内容在圆角容器内独立纵向滚动，右侧保留滚动条槽位并支持拖动、滚轮与键盘。弹窗和证据详情采用内部滚动，表格仅在自身容器内横向滚动。
- 商品名称使用品牌/品名/规格摘要；完整电商标题留在详情。缺样本时显示导入操作，不用虚构统计填满画面。
- 商品图片只承担识别用途，使用真实对象缩略图；不需要营销插图、背景纹理、3D 或新增生图素材。

## 主流程与状态
新建对象/直接导入 → 字段映射与样本预览 → 开始深度分析 → 查看结果与失败项 → 证据 → 行动。

区分未导入、待分析、进行中、部分成功、完成、失败、取消和中断。保留输入与已有结果，恢复后不自动调用模型。运营方案由用户按需生成，事实与建议分层。

## 动效与可访问性
- 主按钮按下约 80ms，完成/失败显示明确文本；不依赖图标颜色判断状态。
- 标签与证据抽屉使用 160–220ms 过渡，业务状态立即生效。
- 首次进入只做一次 180ms 内容显现，刷新数据不反复播放；减少动态效果时直接到位。
- 390px 单列、顶部紧凑导航，外框仍保留圆角及内滚动；表格可横向滚动。键盘焦点可见，弹窗限制焦点并在关闭后归还触发按钮。

## 验收边界
本说明是实施决定，不代表已经截图验收。视觉、交互、对比度及运行验证等待用户批准后执行；本轮不因技能的默认评审要求派代理或自行检查。
