可信度评分细则

ReviewPilot v4.1.6 | 更新日期：2026-08-19

1. 评分体系概览

ReviewPilot 的可信度评分由 两个层级 组成，从单条评论到整体商品口碑，逐层聚合：

单条评论分析
→
LLM 交叉验证
→
单条可信度 (0-100)
→
统计异常检测
→
整体可信度 (0-100)
核心原则：所有评分基于 LLM 语义分析 + TF-IDF 统计检测，temperature=0 确保相同输入产生相同结果。LLM 结果通过文件缓存保证一致性。

2. 单条评论可信度评分（LLM 交叉验证）

每条评论经过 三步分析 后，由 LLM 进行交叉验证并给出 0-100 的可信度分数：

2.1 分析流程

步骤分析维度输入输出
1情绪识别评论内容、评分、平台9类情绪分类 + 反讽检测
2有效性检测评论内容、产品名、相似评论数8类有效性分类（1真实+7无效）
3交叉验证情绪结果 + 有效性结果可信度分数 + 风险等级

2.2 评分区间

分数区间等级含义
80-100 低风险 真实有效的好评，情绪正面且内容具体
60-79 中风险 真实有效的差评，虽然负面但信息有价值
30-59 中风险 反讽/隐性情绪，情绪真实但需关注产品问题
0-29 高风险 模板化/AI生成/高度可疑，无效评论

2.3 交叉验证规则

规则1：反讽 + 模板化 → 高风险
疑似水军使用模板批量刷差评，评分极低（0-30分）
规则2：真诚好评 + AI生成 → 高风险
AI生成的虚假好评，虽有正面情绪但非真实用户（0-30分）
规则3：高分低评 + 具体性低 → 中风险
刷好评但内容随意，评分与内容矛盾（30-50分）
规则4：正面情绪 + 真实有效 → 低风险
正常好评，情绪正面且内容真实（80-100分）
规则5：直接差评 + 真实有效 → 中风险
真实用户表达不满，虽负面但信息有价值（60-80分）

3. 情绪分类体系（9类）

情绪识别是可信度评分的第一步，分为三大类九个子类：

大类子类说明
显性情绪真诚好评评分高，评论正面且包含具体使用体验
直接差评评分低，评论直接表达不满
客观中性评分中等，评论客观描述优缺点
隐性情绪反讽/阴阳怪气文字表面正面，实际表达不满或嘲讽
明褒暗贬表面夸某方面，实则暗示其他方面差
隐性抱怨不直接说不好，通过细节描述暗示不满
评分-评论矛盾高分低评评分4-5星，但评论内容负面
低分高评评分1-2星，但评论内容正面
评分极端文本中性评分1星或5星，但评论平淡无情绪

4. 有效性分类体系（8类）

有效性检测判断评论是否来自真实用户，分为1类真实+7类无效：

分类类别判定依据
真实真实有效包含具体使用体验，语言自然口语化
无效模板化好评高度同质化，如"好评好评好评好评"
无效套话堆砌堆砌通用赞美词，缺乏具体体验
无效批量复制多条评论高度相似，疑似复制粘贴
无效时间集中异常短时间内批量发布
无效内容偏移评论与产品核心功能无关
无效用户行为异常新注册账号、高频评价等
无效AI生成语言过于规范，缺乏口语化表达
相似评论数（similar_count）：由 TF-IDF + 余弦相似度计算（阈值 0.7），统计当前评论与同批次其他评论的相似度。相似度越高，有效性检测中越可能被判为"批量复制"。

5. 整体可信度评分（TrustReportEngine 统计检测）

在单条评论分析完成后，TrustReportEngine 对全部评论进行 6维统计异常检测，从 100 分开始扣分：

整体可信度 = 100 - 时间突发扣分 - 重复组扣分 - 评分异常扣分 - 长度均匀度扣分 - 短语重复扣分 - 评分矛盾扣分

5.1 扣分明细

检测维度扣分规则上限
时间突发检测 若某日评论数超过日均 3 倍，扣 15 分 -15
TF-IDF 重复检测 每组重复评论扣 10 分 -25
评分分布异常 5星或1星占比超过 80%，扣 15 分 -15
长度均匀度 评论长度越均匀（疑似模板），扣分越多 -15
短语重复检测 每条重复短语扣 5 分（4-gram 分析） -20
评分-情感矛盾 每条矛盾评论扣 3 分 -15

5.2 风险等级映射

整体可信度风险等级建议
≥ 70 分low评论整体可信，可正常参考
40-69 分medium存在可疑评论，需关注
< 40 分high大量可疑评论，建议深入调查

6. 关键技术参数

参数值说明
LLM temperature0.0确保分析结果确定性
LLM 结果缓存文件级缓存（.llm_cache/）相同 prompt 永远返回相同结果
重复检测阈值0.85（余弦相似度）TrustReport 重复组判定
相似度邻居阈值0.7（余弦相似度）单条评论 similar_count 计算
时间突发倍数3.0超过日均评论数 3 倍视为突发
评分异常占比80%单档评分占比超过 80% 视为异常
n-gram 大小4短语重复检测的 token 级窗口

7. 平均可信度展示

界面上展示的"平均可信度"是所有单条评论 trust_score 的算术平均值：

平均可信度 = Σ(每条评论 trust_score) / 评论总数

注：平均可信度反映单条评论层面的可信程度；Trust Report 的整体可信度则从群体统计角度检测异常模式，两者维度互补。
