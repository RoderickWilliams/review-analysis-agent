Review Intelligence · 本地优先

评论区里的问题，能不能一路追到原句？

ReviewAgent 是一个面向电商运营的本地评论研究工作台：采集跨平台评论，做情绪与刷评信号判断，再把每条痛点、每个动作绑回评论原句。

9 类情绪分类（含反讽、明褒暗贬、评分矛盾）
5 项统计信号：时间突发、近重复、评分异常、长度均匀度、重复短语
18+评论溯源字段，6 个关键字段做完整性校验
3 个已跑通入口：CLI、HTTP API、Web 工作台

它是怎么工作的

  • 采集：DrissionPage 驱动专用浏览器读公开评论，京东用 Patchright 做 DOM 回退，可选 Scrapling 后端；按平台“接口 → 浏览器 → DOM”降级，采不到就记录缺口，不补造数据。
  • 判断：模型逐条给情绪与内容疑点；统计引擎独立算评论可信度，两者交叉验证，不把模型输出当唯一结论。
  • 落地：痛点必须对上评论原句；再生成运营动作、商品卖点、客服话术和小红书种草模板。卖点只取正向原句，缺陷说明进入客服与行动。
  • 回查：每条结论带评论编号、原句、来源和定位；未通过原句校验的提议单独列出，不计入结论。

技术结构

Python / FastAPISQLiteDeepSeek / OpenAI 兼容 APIDrissionPagePatchrightScrapling（可选）多 Key 轮换人民币预算上限

工作台是单页前端，服务只监听 127.0.0.1；模型 Key 只存在进程内存里，评论、报告和人工标注默认保存在本机。仓库同时附带 DSH 插件与 Agent Skill 的接入代码，桌面安装包只有构建配置。

本地运行

git clone https://github.com/RoderickWilliams/review-analysis-agent.git
cd review-analysis-agent
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[api,scrape,import]"
.venv\Scripts\python.exe run_local.py --port 64628
# 打开 http://127.0.0.1:64628/app/

需要 Python 3.10+、Windows 10/11 和 Chrome/Edge；模型 Key 在本地工作台里配置。
