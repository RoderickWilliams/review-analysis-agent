# 工作台升级交付说明

本轮完成源代码实施，尚未执行测试、构建或界面验收。既往版本的测试结果不能代表本轮改动。

## 数据与分析

- `review_data.py` 统一验证原文、评分、日期和编号；缺失评分为 `null`，缺失发布时间为空，导入时间独立保存。
- 三阶段模型响应验证后才算成功。异常、空内容、错误类型或越界分数保留为失败；成功统计不把它们算作中性或常规评论。
- 情绪是正面、负面、中性三类；反讽独立计数。负面与反讽不直接降低模型可信度。缺少证据时允许未知有效性和空分数。
- 统计 Trust Report 是规则信号，区间未经真实性概率校准。模型分数也不能认证作者身份、交易真实性或 AI 来源。
- 请求级 Key 切换有界；认证、配额、限流错误可尝试下一个已配置通道；同一组 Key 必须适用于同一个网关。
- HTML 转义模型和原文内容，CSV 中和公式前缀。逐条原文导出保留完整正文。

## 持久任务与交互

`POST /v1/analysis` 只解析对象并创建草稿，保存完整 request、reviews、results 和报告。商品链接解析会访问对应公开页面；商品名或数据集名称可离线创建。

| 操作 | 接口 | 行为 |
| --- | --- | --- |
| 文件预览 | `POST /v1/import/preview` | CSV / XLSX / JSON / TXT，字段映射、逐行错误，不保存上传文件 |
| 保存评论 | `POST /v1/analysis/{id}/reviews` | 追加或替换；相同编号正文改变后重新分析，清除过期洞察 |
| 深度分析 | `POST /v1/analysis/{id}/run` | operation=analyze，逐条三阶段分析，再做痛点、改进、选题和内容草稿 |
| 取消 | `POST /v1/analysis/{id}/cancel` | 停止后续模型请求；已发送请求等待返回，可能仍计费 |
| 继续 | 同一 run 接口 | 复用成功条目，继续未完成条目；洞察阶段重新整理 |
| 设置 | `PATCH /v1/analysis/{id}` | 保存归属、档位、时间窗、来源，不丢原文 |
| 行动 | run operation=operations | 根据有原句支持的改进建议整理行动，不另调用模型 |
| 编辑行动 | `PATCH /v1/analysis/{id}/actions/{action_id}` | 负责人、截止日期、状态、验证指标 |
| 导出 | `reviews.csv` / `actions.csv` / `report.html` | 原文结果、行动清单、离线研究报告 |

SQLite 保存逐条进度；进程重启后运行态标为中断，点击继续才重新启动。调度器为**单服务进程**，不支持多个 Uvicorn worker 共享同一个任务库。最多 2 个任务并发，运行与排队合计最多 8 个；单份工作台最多 500 条。每次进度保存只更新统计，任务结束时汇总完整报告。

成功条目仅在原文、模型、提示词版本及同批相似度上下文仍匹配时复用。

痛点最多取 200 条成功样本均匀抽样，分批提取；报告保存实际覆盖范围。引语校验检查原句是否出现在对应评论中；它不能独立验证评论事实。未通过引语校验的提议不进入痛点与选题主清单。

## 设计实现

默认入口 `/app/`：浅灰绿背景、白色工作区、细边框、绿色强调、紧凑表格。左侧为总览、评论库、用户洞察、行动计划、分析历史。图表来自实际发布时间；未知日期不进入时间图。没有样本时提供导入入口，不展示演示指标。

具备评论搜索、来源和状态筛选、排序、40 条分页、原文证据抽屉、文件映射、任务进度、失败重试和历史恢复。弹窗使用原生 dialog；支持键盘关闭、Ctrl/⌘+K 搜索、减少动画偏好、浅色/深色/跟随系统。主题与选中分析编号保存在浏览器；访问令牌只放当前页面内存。

旧版 A 位于 `/app-classic/`，旧版 B 位于 `/app-redesign/`；保留作兼容参考，新增任务和导入功能以默认工作台为准。Streamlit 仍由 `reviewagent app` 启动。

## 采集的实际边界

- 档位：轻量 2 来源×30 条，标准 5×100，深度 10×200；自定义来源上限 20、每来源上限 500，整份仍限 500。
- 时间窗优先；不足时最多补充 30 条更早样本，未知日期另记，不伪造发布时间。
- 增量按平台、来源与评论标识合并；没有平台原始 ID 时使用导入指纹，不能保证识别所有平台重排和重复记录。
- 京东、淘宝公开搜索页只尝试解析真实商品链接。页面受登录或风控限制时记录缺口，不生成候选。
- 小红书复用现有采集端；自动跨平台找同款未完整实现，需要用户补充并确认笔记链接。
- 未取得价格、销量和评论总量时不按这些字段排序。未实施登录、风控绕过或真实平台采集验收。

## 交付与验证

安装使用项目虚拟环境；新增 Excel 为可选扩展，不要求全量浏览器依赖。PyInstaller 和 wheel 仅包含包代码与明确静态资源，不复制 `.env`、Cookie、profile、数据库和输出。桌面版数据默认位于用户 LocalAppData/ReviewAgent，旧 JSON 历史默认不迁移。

工作流只设置 `workflow_dispatch` 手动入口，尚未触发。Python CI 的设置方式参考 [GitHub 官方文档](https://docs.github.com/en/actions/tutorials/build-and-test-code/python)。本轮也未推送、发布、构建安装包或改动现有用户数据库。

待用户一次明确批准后，执行约定范围的离线回归、脚本语法、wheel 资源检查，以及隔离数据和假模型的桌面/窄屏/键盘主流程验证。真实模型质量、登录采集与公开部署不在该验证范围内。
